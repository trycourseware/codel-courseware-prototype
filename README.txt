CODeL Courseware: clickable prototype (version 8.1)
University of Education, Winneba · College for Distance and e-Learning
Prepared by Dr Beatrice Torto and Dr Enusah Abdulai, September 2026

HOW TO OPEN
  Double-click index.html (Chrome, Edge or Firefox). No internet is needed, except for the optional live AI mode.
  To use it on phones and tablets, host this folder on a web server (for example GitHub Pages).

HOW TO SIGN IN
  Use an index number (students) or staff ID and password from the private workbook
  "CODeL-prototype-demo-accounts.xlsx". The workbook is NOT part of this folder; keep it private.
  The sign-in page also has "Sample student" and "Sample tutor" buttons for quick demonstrations.

WHAT IS INSIDE
  1062 demo accounts (1000 students across 16 study centres, plus tutors, coordinators, study-centre
  coordinators, helpdesk officers and administrators); 164 course books with canonical page numbers;
  quizzes; past questions; online exams; course discussions; study groups; an AI study assistant; staff views.

DATA
  All activity is stored in this browser's local storage only. Profile > "Reset the whole demo" clears it.
  People, index numbers, course-book text and questions are fictional samples.
